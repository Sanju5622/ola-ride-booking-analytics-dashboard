 # Ola Ride Booking Analytics Dashboard

## Project Overview

The Ola Ride Booking Analytics Dashboard is a data analytics project developed to analyze ride booking operations and uncover actionable business insights. The dashboard provides a comprehensive view of booking trends, revenue performance, customer behavior, ride cancellations, ratings, and demand patterns using interactive visualizations.

## Problem Statement

Ride-hailing companies generate large volumes of booking data daily. Analyzing this data is essential for understanding customer preferences, monitoring operational efficiency, identifying cancellation trends, and improving overall business performance. This project aims to transform raw booking data into meaningful insights through data analysis and visualization.

## Tools Used

* SQL (Data Analysis & Querying)
* Microsoft Excel (Data Cleaning & Preprocessing)
* Power BI (Dashboard Development & Visualization)

## KPIs Analyzed

* Total Bookings
* Total Revenue
* Booking Status Distribution
* Cancellation Rate
* Customer Ratings
* Driver Ratings
* Average Ride Distance
* Revenue by Vehicle Type
* Peak Demand Hours
* Most Preferred Payment Methods

## Dashboard Features

### Booking Analysis

* Total ride bookings
* Booking status breakdown (Completed, Cancelled, Incomplete)
* Daily booking trends

### Revenue Analysis

* Total revenue generated
* Revenue contribution by vehicle type
* Revenue trends over time

### Cancellation Analysis

* Customer cancellation patterns
* Driver cancellation patterns
* Overall cancellation percentage

### Customer & Driver Insights

* Average customer ratings
* Average driver ratings
* Top customers based on booking value

### Demand Analysis

* Peak booking hours
* Most popular pickup locations
* Most popular drop locations
